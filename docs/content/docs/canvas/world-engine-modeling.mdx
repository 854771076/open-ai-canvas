# 世界引擎模型与建模

## 模型库

「组件」及添加面板的道具分类提供原有 63 项道具和从导演台引入的 136 项参数化预设。新增内容包含 16 种基础／结构形状，以及家具、生活道具、建筑构件、楼梯与通道、道路、植物、地形、建筑外壳、工业施工、古装舞台和车辆。预设是程序化白模，部分题材与原目录重叠；不是 136 个写实模型文件。

道具尺寸、细分、门窗开合等参数在属性面板调整。门板和轮轴的层级变换烘焙进静态几何；当前不提供门窗或轮子动画。目录道具继续使用共享几何和实例化渲染。源库使用 MIT，来源与声明保存在 `web/src/lib/canvas/previs/shotloom/`。

## 自由造型

左侧「造型」打开配方编辑器。通过部件树、尺寸、位置、旋转、父部件、镜像、材质和切割设置组合模型；曲线与截面使用控制点表单。支持 blob、box、cylinder、torus、frame、lathe、tube、extrude、loft、convex、scatter。

可导入或导出配方 JSON；高级 JSON 用于孔洞、表面起伏、渐变和复杂组合。导入上限为 1 MiB。配方保存为场景对象的 `sculpt` 字段；未知字段、不适用字段、父链环、退化轮廓和超限输入会被拒绝。无效编辑和布尔生成失败保留上一份有效模型，并显示错误；有未应用的 JSON 或错误时不能确认。

配方单位为米、Y 向上，部件旋转单位为度；这与场景对象变换中的弧度不同。尺寸不随父部件缩放。镜像展开后最多 48 个部件，父链深度最多 8，禁止嵌套镜像；单个 scatter 最多 4000、整份配方最多 12000 个实例。切割体通过 parent 指向被切割部件，支持差集和交集；普通叠放不会自动焊接。

Sculpt 来源使用 AGPL-3.0-or-later，原始许可、第三方声明和宿主修改说明保存在 `web/src/lib/canvas/previs/sculpt/`。几何由本机浏览器生成，不是任意文本或图片直接生成精细模型的服务。复杂布尔计算同步执行，宜使用少量部件逐步调整。

## 三角网格编辑

左侧「建模」从方块开始。选中静态道具、基础形状、模型或自由造型后，可在属性面板使用「复制为可编辑网格」；原对象保留。已保存的编辑网格提供「编辑顶点／边／面」入口。

- 单击选择顶点、边或三角面，Shift／Ctrl／Command 多选；「框选穿透」按投影区域选择，包括背面。
- 选择后通过手柄移动、旋转、缩放，也可输入精确位移；「适配模型」重新取景。
- 支持区域面挤出、删除面、拆分边、合并顶点，几何变化后自动重算法线。拖动作为一次撤销事务，拓扑变化后清空失效选择；最多保留 30 次编辑历史。
- 每个编辑网格最多 2 万顶点、4 万三角面，坐标绝对值不超过 1 万米。退化面、非法索引和不适用的非流形边操作会明确拒绝。

编辑副本保留几何和面颜色；贴图不随拓扑编辑保留，带骨架、蒙皮、变形或动画的模型需要先烘焙为静态模型。转换为网格后，不反推原配方，也不再跟随原目录参数变化。

## 保存与同步

手动新建或复制的网格导出为独立 GLB 模型素材，场景保存素材 ID、storageKey、变换、可编辑标记和局部包围盒。Agent 创建的 `kind=mesh` 在场景内保留有界拓扑，支持 Agent 与手动编辑往返；手动保存同样导出独立 GLB 素材，场景保留原网格 ID 与拓扑。素材元数据保留包围盒，从素材库再次加入时保持米制尺寸。编辑网格不会再次执行普通导入模型的两米归一化。

网格保存期间锁定编辑；关闭编辑器或账号切换取消旧会话。原网格被其他操作更新时拒绝覆盖，重新打开后再编辑。素材上传失败的本机缓存与服务端同步分开提示；场景继续沿用世界引擎自动保存，加入素材库不代表场景已经完成服务端持久化。

## Agent 接入

目录 ID 使用原有道具 ID 和新增的 `shotloom-` 前缀 ID，前后端参数白名单同步。调用 `previs_scene_read(manual="sculpt")` 获取按需配方说明；使用 `object_add kind="sculpt"` 创建，或 `object_update sculpt={...}` 整体替换配方，先读取快照及已有配方。`includeTransforms=true` 返回规范化配方，不返回模型素材 URL 或 storageKey。

没有合适模型时，Agent 根据外形选择 Sculpt 或三角网格自己建模。`previs_scene_read(manual="mesh")` 返回顶点、面索引、绕序、颜色和更新规则；`object_add kind="mesh" mesh={version:1,vertices,triangles,colors}` 创建真实拓扑，`object_update` 整体替换。配合 `objectIds` 和 `includeTransforms=true` 读回已有拓扑后再修改，保留对象身份、变换和动画；普通摘要只返回网格数量和范围。现有 GLB／目录道具的转换仍通过手动编辑器，不会由 Agent 隐式转换。

道具参数必须来自 `catalog.params`；固定 `car` 没有可调参数，可调轿车用 `shotloom-vehicle-sedan`。Sculpt 圆锥使用 `cylinder+taper=1`。这类字段错误交回模型修正，沿用三次纠错上限，纠正后仍需原有审批。

Agent 入口保留现有权限、审批和 snapshotHash 校验。服务端校验配方与拓扑合同，不执行脚本；服务端写入成功不能当作已观察到画面或布尔结果。世界引擎所有场景合计 JSON 上限仍为 1 MiB，Agent 应从低面数模型开始，逐步读回与预览核对。
