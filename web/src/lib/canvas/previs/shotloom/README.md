# Shotloom 静态道具构建器

来源：standalone-director-desk-v3，提交 `71a7d74d49287ee797722edd331967494047a2ab`。源库 MIT 许可见本目录 `LICENSE`。

仅保留 136 个现代静态预设及其程序化构建依赖：16 个形状、40 个家具，以及生活道具、建筑构件、楼梯交通、道路、植物、地形、建筑、工业、古装舞台、车辆各 8 个。不包含旧模型、演员、动物、灯光、编辑器或动画运行时。

`model.ts`、`asset-catalog.ts` 和目录类型是最小本地适配合同。源构建器保留几何与参数语义；集成适配器将 Group 层级变换烘焙到克隆几何，保留接触锚点，映射到预演材质角色。门窗及集装箱开合使用当前参数的静态姿态；车辆轮子等动态标识不会接入动画运行时。

宿主将零圆角盒改用普通 BoxGeometry，保持直角外形和尺寸，避免建筑窗框的大量无效细分；有圆角的零件仍使用 RoundedBoxGeometry。
